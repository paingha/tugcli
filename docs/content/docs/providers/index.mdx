A **provider** is a place that knows about Kubernetes clusters. Each one can
list clusters for an **account** and hand out credentials for them. Eight
providers are built into tug, and nine more come as first-party plugins that
you [add when you need them](/docs/plugins/managing).

## Built in

| Provider | An account is… | Credentials come from… |
| --- | --- | --- |
| [`kubeconfig`](/docs/providers/kubeconfig) | one kubeconfig file | the file; embedded tokens and keys move to the keychain |
| [`local`](/docs/providers/local) | one local tool: kind, k3d, minikube, Docker Desktop, OrbStack, Rancher Desktop | the tool's client certificate, read fresh each time |
| [`aws`](/docs/providers/aws) (EKS) | one AWS profile | short-lived EKS tokens; no AWS CLI needed |
| [`google`](/docs/providers/google) (GKE) | one Google Cloud project | short-lived OAuth tokens from Application Default Credentials |
| [`azure`](/docs/providers/azure) (AKS) | one subscription your Azure sign-in sees | a short-lived Entra token, or a local-account cluster's user credential |
| [`capi`](/docs/providers/capi) (Cluster API) | a management cluster in your catalog | each workload cluster's `<name>-kubeconfig` Secret |
| [`argocd`](/docs/providers/argocd) | an Argo CD install in your catalog | Argo CD's cluster Secrets |
| [`clusterprofile`](/docs/providers/clusterprofile) | a SIG Multicluster hub in your catalog | the exec plugin your providers file names for each access provider |

## Plugins

| Provider | An account is… | Credentials come from… |
| --- | --- | --- |
| [`akamai`](/docs/providers/akamai) (LKE) | one Akamai Cloud (Linode) token | the LKE kubeconfig's token, kept in the keychain; `tug auth rotate` regenerates it |
| [`coreweave`](/docs/providers/coreweave) (CKS) | one CoreWeave API token | the API token, or an ID token from your OIDC issuer (`tug auth login`) |
| [`crusoe`](/docs/providers/crusoe) (CMK) | a Crusoe access key and secret key | the cluster's OIDC issuer (`tug auth login`), else the admin certificate |
| [`digitalocean`](/docs/providers/digitalocean) (DOKS) | a personal access token | a short-lived token from DigitalOcean's credentials API |
| [`nebius`](/docs/providers/nebius) (mk8s) | a `nebius` CLI profile | the CLI's `get-token`, run by kubectl |
| [`rancher`](/docs/providers/rancher) | a Rancher server and an API token | a kubeconfig token generated per cluster |
| [`tailscale`](/docs/providers/tailscale) | your tailnet | your tailnet identity, through the Kubernetes operator's API server proxy |
| [`teleport`](/docs/providers/teleport) | your `tsh` sign-in | `tsh kube credentials`, run by kubectl |
| [`vultr`](/docs/providers/vultr) (VKE) | a Vultr API key | the cluster's client certificate |

aws              0.5.0     built-in   accounts,list,credential                   -
azure            0.5.0     built-in   accounts,list,credential                   -

Providers with `accounts` can look around your machine, so a bare
`tug import` finds them. The others need you to say which account to import.

## Providers that read another cluster

`capi`, `argocd` and `clusterprofile` find clusters by reading a cluster you've
already imported: a Cluster API management cluster, the cluster Argo CD runs
in, or a multicluster hub. Import that cluster first, then point the provider
at it by name:

```bash
tug import capi --account mgmt --set cluster=mgmt-eu
tug import argocd --account gitops --set cluster=ops-eu
```

## Settings

Some providers take settings, passed with `--set key=value` when you import:

```bash
tug import aws --account work --set regions=eu-west-1,us-east-1
tug import coreweave --account acme --set auth=oidc --set zone=US-EAST-04A
```

Settings are saved with the source, so `tug sync` uses them again. To change
them, import the same account again with every setting you want: the new set
replaces the old one. If you pass a setting a plugin doesn't know (usually a
typo), tug warns you and lists the ones it does.

## Need another provider?

Anything with an API that lists clusters can become a provider.
[Write a plugin](/docs/plugins/writing) in Go, Python or any language that can
read and write JSON.
