tug keeps everything in four folders, following the XDG conventions on every
platform. None of them ever holds a plain-text secret.

| Folder | macOS and Linux | Windows | Holds |
| --- | --- | --- | --- |
| Config | `~/.config/tug` | `%AppData%\tug` | Settings you edit |
| Data | `~/.local/share/tug` | `%LocalAppData%\tug` | State tug owns |
| Cache | `~/.cache/tug` | `%LocalAppData%\cache\tug` | Safe to delete at any time |
| Runtime | `$XDG_RUNTIME_DIR/tug`, else `$TMPDIR/tug-<uid>` | `%TEMP%\tug-<user>` | Sessions and tugd |

The `XDG_*` variables move these on any platform. `TUG_HOME` puts all four
under one folder instead, as `config/`, `data/`, `cache/` and `run/`.

| File | What it is |
| --- | --- |
| `config.yaml` | Your [settings](/docs/reference/configuration). Optional. |
| `profiles/<name>.yaml` | Your [profiles](/docs/guides/profiles): cluster, namespace, safety, aliases and port-forwards. |
| `catalog.yaml` | Imported sources and their clusters, with labels and [tunnels](/docs/guides/tunnels). No secrets. |
| `pins.yaml` | The [pin files](/docs/guides/pins) you've allowed, by path and content. |
| `secrets.enc` | The encrypted secret store, only if you use the `file` backend. |
| `teams/teams.yaml` | The [team catalogs](/docs/guides/teams) added with `tug team add`. |
| `teams/<team>/` | The last good version of a team's catalog and its signature, checked again on every read, and the version accepted, so an older one is refused. |
| `plugins/<name>/<version>/` | Installed plugins. `links.yaml` lists linked ones. |
| cache | API discovery data, to make commands faster. |
| `sessions/<id>/` | One folder per terminal: its kubeconfig (no secrets), prompt text (which the hook reads, with when an unlock ends) and state. |
| `tugd.sock`, `tugd.log` | tugd's private control socket and its log. |

## Permissions

Files in these folders are readable only by you (`0600`), and folders are
`0700`. tug writes state files atomically, so a crash never leaves a
half-written catalog. It refuses to use a runtime folder that other users
could change.
