See [Read-only sessions](/docs/concepts/read-only) for how these fit together.

## tug unlock

Allow writes on a read-only session for a while. Only this terminal is
affected. On a read-write session, tug says so and does nothing.

```bash
tug unlock [duration]
```

The duration defaults to `15m`. Use any Go duration such as `90s`, `30m` or
`1h`. When a [team policy](/docs/guides/teams#safety-policies) limits
unlocks on the cluster, a longer duration is refused, and without one tug
unlocks for the limit if it is shorter than `15m`.

```console
$ tug unlock 30m
Unlocked: writes allowed on prod-eu until 4:15PM
```

## tug lock

Make a read-only session read-only again now, ending an unlock early.

```bash
tug lock
```
