tug works without any configuration. When you want to change a default, create
`config.yaml` in tug's config folder:

| Platform | Path |
| --- | --- |
| macOS and Linux | `~/.config/tug/config.yaml` (or `$XDG_CONFIG_HOME/tug/config.yaml`) |
| Windows | `%AppData%\tug\config.yaml` |
| With `TUG_HOME` set | `$TUG_HOME/config/config.yaml` |

tug reads the file strictly: a misspelt key is an error, so you'll know
straight away rather than wondering why a setting does nothing.

## A complete example

```yaml title="~/.config/tug/config.yaml"
# Where secrets live: auto, keychain or file.
keyring:
  backend: auto

# The kubectl to run for passthrough commands and tug top.
kubectl: kubectl

guard:
  # A cluster matching ANY of these label sets opens read-only.
  readOnlyLabels:
    - env: prod
    - team: payments
      tier: critical

plugins:
  # Built-in provider names a plugin may replace.
  allowOverride: []
  # Signed plugin indexes for tug plugin search and install <name>, in order.
  indexes:
    - name: acme
      url: https://plugins.acme.example/index.yaml
      publicKey: <base64 ed25519 public key>
  # Time limits per plugin operation.
  timeouts:
    list: 60s
    credential: 15s
    rotate: 2m

sessions:
  # Remove sessions untouched for this long.
  maxAge: 168h

oidc:
  # Where the browser comes back to after an OpenID Connect sign-in.
  listenAddresses: [127.0.0.1:8000, 127.0.0.1:18000]

policy:
  # Policy packs for tug check, besides the built-in baseline.
  packs:
    - path: policies/platform.yaml
    - url: https://policies.example.com/payments-1.2.0.yaml
      sha256: "<sha256 of the file>"
  # The packs tug check runs without --pack. Default: all of them.
  default: [baseline, platform]
```

## plugins

<TypeTable
  type={{
    allowOverride: {
      type: 'string[]',
      default: '[]',
      description: 'Built-in provider names (such as aws or google) that a plugin of the same name may replace.',
    },
    indexes: {
      type: '{ name, url, publicKey }[]',
      default: '[]',
      description:
        'Signed plugin indexes that tug plugin search and tug plugin install <name> use, in order. The signature is read from url + ".sig" and must match publicKey (base64 ed25519). There is no default index yet.',
    },
    timeouts: {
      type: 'map of operation to duration',
      default: '{list: 30s, credential: 10s, rotate: 60s, others: 30s}',
      description:
        'Per-operation time limits: describe, accounts, list, credential, rotate, checkAccess. Operations left out keep the default. A call that runs out of time fails as Unavailable.',
    },
  }}
/>

## policy

<TypeTable
  type={{
    packs: {
      type: '{ path } | { url, sha256 }[]',
      default: '[]',
      description:
        'Policy packs for tug check, besides the built-in baseline. A relative path is taken from the config folder. A url must be https and needs the sha256 of the file, which pins it: a pack that changes is refused until you update the pin. A sha256 on a path is checked too. See Policy packs.',
    },
    default: {
      type: 'string[]',
      default: 'every pack',
      description: 'The packs tug check runs without --pack, by name. Leave baseline out to stop it running by default.',
    },
  }}
/>

Durations are written as strings such as `"30s"`, `"15m"` or `"168h"`.
