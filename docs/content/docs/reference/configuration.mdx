tug works without any configuration. When you want to change a default, create
`config.yaml` in tug's config folder:

| Platform | Path |
| --- | --- |
| macOS and Linux | `~/.config/tug/config.yaml` (or `$XDG_CONFIG_HOME/tug/config.yaml`) |
| Windows | `%AppData%\tug\config.yaml` |
| With `TUG_HOME` set | `$TUG_HOME/config/config.yaml` |

tug reads the file strictly: a misspelt key is an error, so you'll know
straight away rather than wondering why a setting does nothing.

## A complete example

```yaml title="~/.config/tug/config.yaml"
# Where secrets live: auto, keychain or file.
keyring:
  backend: auto

# The kubectl to run for passthrough commands and tug top.
kubectl: kubectl

guard:
  # A cluster matching ANY of these label sets opens read-only.
  readOnlyLabels:
    - env: prod
    - team: payments
      tier: critical

plugins:
  # Built-in provider names a plugin may replace.
  allowOverride: []
  # Signed plugin indexes for tug plugin search and install <name>, in order.
  indexes:
    - name: acme
      url: https://plugins.acme.example/index.yaml
      publicKey: <base64 ed25519 public key>
  # Time limits per plugin operation.
  timeouts:
    list: 60s
    credential: 15s
    rotate: 2m

sessions:
  # Remove sessions untouched for this long.
  maxAge: 168h

oidc:
  # Where the browser comes back to after an OpenID Connect sign-in.
  listenAddresses: [127.0.0.1:8000, 127.0.0.1:18000]

intelligence:
  # Let tug why --deep ask a model to explain a diagnosis. Off by default.
  enabled: false
  provider: anthropic
  model: claude-opus-5-5
  monthlySpendCapUSD: 20
```

## intelligence

Settings for [`tug why --deep`](/docs/guides/ai-explanations), which sends
redacted evidence about an object to a model provider after showing it to you
and asking. API keys are never set here: `tug intelligence key set <provider>`
keeps one in the keychain, or set `TUG_SECRET_<PROVIDER>_API_KEY`.

<TypeTable
  type={{
    enabled: {
      type: 'boolean',
      default: 'false',
      description: 'Turns tug why --deep on. Without it, --deep fails before anything is read or sent.',
    },
    provider: {
      type: 'string',
      default: '"anthropic"',
      description: 'anthropic, openai, mistral, or custom for any other OpenAI-compatible API (Ollama, vLLM, LiteLLM).',
    },
    model: {
      type: 'string',
      default: 'the provider\'s: claude-opus-5-5, gpt-6.2-astra, mistral-large-latest; none for custom',
      description: 'Any model id the provider serves. tug why --model overrides it for one call.',
    },
    baseURL: {
      type: 'string',
      default: 'the provider\'s API; required for custom',
      description: 'Where requests go, for a gateway or a custom endpoint, such as http://localhost:11434/v1. It must use https unless it is on this machine.',
    },
    timeout: {
      type: 'duration',
      default: '"5m"',
      description: 'How long one request may take.',
    },
    maxOutputTokens: {
      type: 'integer',
      default: '16000',
      description: 'The longest answer, thinking included. The cost estimate counts up to it.',
    },
    monthlySpendCapUSD: {
      type: 'number',
      default: '0 (no cap)',
      description: 'Refuse a call that could take this calendar month\'s (UTC) spend past it, or whose model has no price.',
    },
    effort: {
      type: 'string',
      default: '"high"',
      description: 'For Anthropic models: how hard the model works on its answer, low, medium, high, xhigh or max.',
    },
    prices: {
      type: '{ model, input, output, cacheRead }[]',
      default: '[]',
      description:
        'Prices in US dollars per million tokens that add to or override the built-in table. model is an id or the start of one; the longest match wins.',
    },
  }}
/>

Durations are written as strings such as `"30s"`, `"15m"` or `"168h"`.
